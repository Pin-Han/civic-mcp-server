# Phase 5：tw-energy 模組（電力）

**目標：** 查詢台電即時發電資訊與備轉容量率

## 5.1 Taipower Client (`src/modules/tw-energy/clients/taipower.ts`)

### API 資訊
- **來源：** 台灣電力公司開放資料（data.gov.tw dataset 8931）
- **URL：** `https://service.taipower.com.tw/data/opendata/apply/file/d006001/001.json`
- **認證：** 免認證（公開資料）
- **更新頻率：** 每 10 分鐘
- **授權：** 政府資料開放授權條款第1版

### 回傳結構

```json
{
  "": "台灣電力公司_各機組發電量即時資訊",
  "": "2026-05-12 16:00",
  "aaData": [
    [
      "1",
      "核能",
      "核二#2",
      "985.0",
      "0.0",
      "",
      "",
      ""
    ],
    [
      "2",
      "燃煤",
      "林口#1",
      "800.0",
      "762.5",
      "",
      "",
      ""
    ]
  ]
}
```

> **注意：** `aaData` 為二維陣列，各欄位順序為：
> 1. 序號
> 2. 機組類型（核能/燃煤/燃氣/燃油/水力/風力/太陽能/抽蓄發電/地熱/其他再生能源）
> 3. 機組名稱
> 4. 裝置容量 (MW)
> 5. 淨發電量 (MW)
> 6-8. 備註欄位

### 資料解析要點

- 數值為字串格式，需 `parseFloat()` 轉換
- 發電類型需分類彙整：火力（燃煤+燃氣+燃油）、再生能源（風力+太陽能+地熱+其他）、核能、水力、抽蓄
- 備轉容量率需自行計算：`(總裝置容量 - 尖峰負載) / 尖峰負載 * 100`
- 或從台電另一個 endpoint 取得（若有即時數據）

## 5.2 get_power_status Tool

```typescript
server.tool(
  "get_power_status",
  "查詢台灣即時電力供需狀態，包含各類發電佔比與總發電量",
  {},
  powerStatusHandler,
);
```

- **快取 TTL：** 180 秒（3 分鐘）
- **快取 Key：** `power-status`
- 無輸入參數（查詢全國即時狀態）

### 輸出格式

```
台灣即時電力狀態（2026-05-12 16:00）
────────────────────────────────
總淨發電量：XX,XXX MW
各類發電佔比：
  - 燃氣：45.2%（XX,XXX MW）
  - 燃煤：25.1%（XX,XXX MW）
  - 再生能源：15.3%（X,XXX MW）
  - 核能：8.0%（X,XXX MW）
  - 水力：3.5%（XXX MW）
  - 其他：2.9%（XXX MW）
```

### 供電燈號對照（參考用）
- 綠燈：備轉容量率 >= 10%（供電充裕）
- 黃燈：6% ~ 10%（供電吃緊）
- 橘燈：< 6%（供電警戒）
- 紅燈：限電準備 / 限電中

> **注意：** 即時備轉容量率需要尖峰負載數據，而 dataset 8931 只有機組發電資料。
> MVP 先呈現各類發電佔比與總發電量，備轉容量率列為中期目標（需找到合適數據源）。
